# База знаний Wizards

Статический сайт на React + Vite. Бэкенд не нужен: статьи — это обычные Markdown-файлы, которые собираются в сайт.

## Запуск

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm run build    # готовый сайт в папке dist/
```

Папку `dist/` можно залить на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages или обычный веб-сервер. Сайт работает из любой подпапки.

### Публикация на GitHub Pages

Проще всего — кнопкой **«Опубликовать»** в редакторе. Под капотом это обычный `git push`: сайт собирается и публикуется сам при каждом push в ветку `main` — это делает [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Один раз включите в репозитории: **Settings → Pages → Source: GitHub Actions**. Ход сборки виден во вкладке **Actions**, сайт открывается по адресу `https://<логин>.github.io/<репозиторий>/`.

### Telegram Mini App

Тот же сайт открывается внутри Telegram как приложение бота — отдельной сборки не нужно. Код интеграции — [`src/lib/telegram.js`](src/lib/telegram.js): он включается только при запуске из Telegram, в обычном браузере сайт работает как раньше.

Внутри Telegram тема повторяет тему Telegram, работает кнопка «Назад», ссылки на `t.me` открываются в самом Telegram, а копирование отзывается вибрацией.

Подключение в [@BotFather](https://t.me/BotFather): `/mybots` → бот → **Bot Settings → Configure Mini App** → адрес сайта. Кнопка у поля ввода — там же, **Menu Button**.

Ссылка на статью: `https://t.me/<бот>?startapp=<раздел>_<статья>`, например `?startapp=rules_chat` откроет `#/rules/chat`.

## Редактор

Статьи, разделы и главную удобнее править в редакторе — это отдельное приложение в папке [`editor/`](editor/README.md) с живым превью, проверкой ссылок, историей версий и загрузкой картинок.

```bash
npm --prefix editor install   # один раз
npm run editor                # откроется http://localhost:5174
```

Редактор пишет прямо в файлы сайта, так что запущенный рядом `npm run dev` обновляется сразу после сохранения.

## Настройка

Название сервера, адреса для Java и Bedrock (с портом и версиями), ссылки сообщества и список разделов задаются в [`src/config.js`](src/config.js).

### Превью ссылки и иконка

- После публикации впишите адрес сайта в `siteUrl` в `src/config.js` и пересоберите сайт — без него Telegram не покажет картинку в превью ссылки.
- Лого сервера — `public/logo.jpg`: оно в шапке сайта, на вкладке браузера и на экране «Домой». Картинка превью — `public/og.png` (1200×630), название на экране «Домой» — `public/manifest.webmanifest`.
- Telegram запоминает превью ссылки. Если поменяли картинку или описание, обновите превью через бота [@WebpageBot](https://t.me/WebpageBot).

## Как добавить статью

Создайте файл `src/content/<раздел>/<имя>.md`. Папка — это раздел, имя файла — адрес статьи (`#/rules/chat`).

```md
---
title: Правила чата
description: Короткое описание под заголовком
order: 2
tags: [чат, мут]
updated: 2026-10-01
---

## Заголовок раздела

Текст статьи…
```

Все поля необязательные:

| Поле | Что делает |
|---|---|
| `title` | Заголовок. Если не указан — берётся первый `# Заголовок` или имя файла |
| `description` | Подзаголовок, участвует в поиске |
| `order` | Порядок в меню (меньше — выше). Без него статьи идут по алфавиту |
| `tags` | Слова для поиска, видны под заголовком |
| `updated` | Дата обновления |

Новая папка сама станет разделом. Чтобы задать ей название, иконку и место в меню — добавьте её в `sections` в `src/config.js`.

## Что поддерживается в тексте

- Обычный Markdown и таблицы. На телефоне широкие таблицы показываются карточками: первая колонка становится заголовком карточки, поэтому ставьте в неё название (команду, чар, предмет).
- Заголовки `##` и `###` попадают в оглавление справа и в поиск.
- Инлайн-команды вида `` `/home` `` копируются по клику, у блоков кода есть кнопка «Копировать».
- Цвета Minecraft: `&bТекст` — цвет действует до следующего кода, `&r` или конца абзаца/ячейки, как в игре. Например, `**&dФеникс**`. В светлой теме светлые цвета показываются на тёмной плашке, чтобы читались.
- Картинки: `![описание](https://ссылка.png "подпись")`. Картинка отдельным абзацем показывается с подписью и открывается в полном размере по клику; подпись необязательна.
- Ссылки на другие статьи: `[Устав](#/rules/charter)`, на раздел статьи: `[Двери шёпота](#/world/movement#двери-шёпота)`, на заголовок в той же статье: `[ниже](#двери-шёпота)`.
- Наказание в правилах — красной меткой: `<span class="penalty">пред + мут</span>`.
- Плашки:

```md
> [!NOTE]
> Примечание

> [!TIP]
> Совет

> [!WARNING]
> Внимание

> [!DANGER]
> Важно
```

## Горячие клавиши

- `↑` `↓` `Enter` — выбор результата
- `Esc` — закрыть
