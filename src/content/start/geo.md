> [!WARNING]
> Из-за технических ограничений этот способ не поможет игрокам с Bedrock. Если вы можете играть только с мобильного устройства, используйте лаунчеры вроде PojavLauncher.
>
> Также при таком входе не будут работать голосовой чат, эмоции и другие моды, которым нужна связь с сервером.

## Данные для входа

Подключайтесь по специальному адресу:

```
wizards.minecraft.in.net
```

Этот способ поможет и игрокам, у которых высокий пинг из-за удалённости от сервера. Физический сервер находится в Москве (Россия).

## Ресурспак

Для некоторых механик сервера нужен ресурспак. Обычно он загружается автоматически при каждом входе, но при входе с Geo-IP этого не произойдёт — без него многие меню и предметы будут отображаться неправильно.

Скачайте ресурспак самостоятельно и положите файл в папку `resourcepacks`:

[скачать wizards_pack.zip](https://www.mediafire.com/file/sw25ybf88rx82ni/wizards_pack.zip/file)

> [!NOTE]
> Ресурспак регулярно обновляется — следите за актуальной версией по ссылке и заменяйте файл. Последнее обновление: **22.09.26**.
