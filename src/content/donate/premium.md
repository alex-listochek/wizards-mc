## Возможности

- Префикс Premium-аккаунта
- Умная сортировка предметов в инвентаре и сундуках
- Автосброс инвентаря по команде
- В 3 раза больше точек дома
- В 3 раза больше слотов на аукционе
- В 2 раза больше приватов
- В 2 раза больше места в эндер-сундуке
- +2 слота для экипировки амулетов
- Создание ваучеров
- Можно узнать место своей смерти
- Можно узнать время до возрождения Дракона
- Шалкер открывается прямо в руке, если зажать Shift
- Невидимые рамки для предметов (Java)
- Форматирование и цвета в сообщениях чата (`&`)
- Форматирование и цвета при переименовании предметов на наковальне (`&` и hex)

## Команды

| Команда | Что делает |
|---|---|
| `/tags` | Установить префикс Premium из коллекции |
| `/voucher <сумма>` | Создать физический носитель вашей валюты (галлеонов) |
| `/dchest` | Координаты места смерти |
| `/dragon` | Время до возрождения Дракона |
| `/dump` | Сбросить инвентарь в ближайшие сундуки в радиусе 10 блоков |
| `/unload` | Разложить предметы из инвентаря в сундуки с такими же предметами в радиусе 10 блоков |
| `/blacklist add <id предмета>` | Добавить предмет в список блокировки сброса через `/dump` |
| `/blacklist remove <id предмета>` | Убрать предмет из списка блокировки сброса |
| `/blacklist show` | Показать предметы, которые не сбрасываются |
| `/sort` | Меню настройки автосортировки в сундуках и инвентаре |
| `/isort` | Отсортировать инвентарь |
| `/isort all` | Отсортировать инвентарь и панель быстрого доступа |
