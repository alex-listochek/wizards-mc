## Java Edition

Адрес сервера:

```
wizards.ru-mc.ru:25603
```

Поддерживаются версии **1.21.4 – 26.2**.

## Bedrock Edition

Адрес сервера:

```
wizards.ru-mc.ru
```

Порт:

```
18570
```

Поддерживаются версии **26.0 – 26.50**.

## Регистрация

При первом входе зарегистрируйтесь: `/register <пароль> <еще раз пароль>`. При следующих входах авторизуйтесь: `/login <пароль>`.

Остальные команды — в [Памятке команд](#/commands/list). Что делать после входа — в статье [Первые шаги](#/start/first-steps).

## Голосовой чат и эмоции

Сервер поддерживает моды [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) и [Emotecraft](https://modrinth.com/plugin/emotecraft).

## Не удаётся зайти?

Если вы играете из другой страны и не можете подключиться, воспользуйтесь [Geo-входом](#/start/geo).

Остались вопросы — напишите в [поддержку](https://t.me/wizticket_bot).
