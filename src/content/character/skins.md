## Bedrock

**1.** На главном экране откройте раздел **Гардероб**.

**2.** В боковой панели найдите раздел **Classic Skins**.

**3.** В подразделе **Скины во владении** импортируйте свой скин в формате **.png**.

![Раздел установки скина в Bedrock](https://i.ibb.co/vsDGmq4/photo-2024-12-06-18-12-53.jpg "Раздел установки собственного скина Bedrock")

Готово!

## Java (TLauncher)

**1.** Добавьте в TLauncher аккаунт с такими параметрами:

- **Логин** — ваш ник;
- **Авторизация без пароля**;
- **Официальные скины Minecraft**.

Затем нажмите **Сохранить аккаунт**.

![Пример настройки аккаунта](https://i.ibb.co/QNwrScs/photo-2024-12-06-18-18-37.jpg "Пример настройки аккаунта")

**2.** Найдите и скачайте подходящий скин в формате **.png**.

**3.** Загрузите файл на хостинг изображений, например [ru.imgbb.com](https://ru.imgbb.com/).

**4.** Получите прямую ссылку на файл — она должна заканчиваться на **.png**.

![Нужная часть ссылки](https://i.ibb.co/CMGtS49/photo-2024-12-06-18-32-23.jpg "Часть ссылки, которая вам нужна, выделена")

**5.** Зайдите на сервер и введите команду со ссылкой на скин:

```
/skin url "https://i.ibb.co/…/skin.png"
```

> [!WARNING]
> Ссылка обязательно должна быть в кавычках.

Готово!
